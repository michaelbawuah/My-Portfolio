# Interactive portfolio source credit

The Spline keyboard at `public/interactive/skills-keyboard.spline` comes from Sylvester Kpei's public portfolio, https://github.com/kpeis695/personal-website, snapshot `0a1aa0516b6c4f448e2b4008122a5898e1059882` retrieved October 4, 2026. Its upstream Git blob is `a8295c1f2a7279177dd7b1fc27a14b4ca365b374`.

The upstream README declares the project available under the MIT License, but the inspected snapshot contains no LICENSE file. The original README is retained as `INTERACTION-UPSTREAM-README.md`; this note does not invent missing copyright terms or independently license third-party logos embedded in the scene.

This integration uses that scene in bounded, lazy-loaded landing, About, and contact components. About has a separate accessible HTML technology explorer. The poses adapt the original hero, skills, and floating-key object names. Full-page menu previews and animated project presentation take inspiration from the same portfolio and the separate MBA~Steins 3D study. The main portfolio's content, branding, multipage structure, images, documents, and light palette remain its own existing assets.

Visible keyboard attribution links to the original repository. No original creator contact endpoint, analytics, personal photos, unrelated projects, or sound effects were imported for this integration. The scene’s existing Inter and Archivo Black fonts are served locally to avoid cross-origin dependencies.

Expanded references: hero text reveals, the magnifying dock, pointer particles, elastic cursor, experience timeline, smooth-scroll behavior, and radial navigation. These behaviors are independently integrated with the main portfolio’s light palette and existing content. The Projects composition also follows the user’s supplied October 4 six-card screenshot. The explicit radial trigger replaces the reference’s context-menu gesture; contact opens a reviewed mail draft rather than copying any third-party email endpoint.

The shared-background update reuses `bongo-cat`, `frame-1`, and `frame-2` from the same credited scene. Original source references are `src/components/animated-background.tsx` and `src/components/animated-background-config.ts` at the recorded snapshot. The upstream cat alternates frames every 100ms; this integration applies it across the shared layout. Its continuously scroll-derived poses are new integration logic; the original switches poses at section thresholds. Day/night recolors the application and scene background, without claiming changes to the original keycap materials.

The section-scene update restores separate assembled, skills, projects/cat, and floating-key compositions within one persistent canvas. A visible toolkit section drives the original `heading`/`desc` variables; exact matching keys depress on selection. The local asset has no Python, PyTorch, C++, Go, or FastAPI key mesh, so those selections update captions without relabeling an unrelated key. The full rounded desktop keycap instances are used at every viewport size. Foreground controls retain input ownership, and the contact section opens a reviewed email draft.

The October 8 shared-renderer correction removes the separate Canvas 2D phone renderer. Every viewport now loads `skills-keyboard-unified.spline` through the same Spline Application, original camera, full rounded keycaps, materials, cat frames, and animation controller. The original scene remains unchanged as the upstream source; the unified copy changes only its font URLs to local assets and sets both desktop and mobile pixel ratios to 2. Rotation, key movement, cat timing, and frame cadence are independent of viewport size. Position and scale adapt to the available screen space. Reduced-motion preferences render a still 3D scene.

The modelling engine (`@splinetool/modelling-wasm` 1.12.0 `process.wasm`) and the scene’s existing Inter/Archivo Black fonts are served under `public/interactive/spline-runtime/`. The renderer pauses in background tabs, retries a failed load once, and reloads after WebGL context restoration. While loading or when WebGL is unavailable, `keyboard-scene-preview.png` shows the user-supplied October 8 screenshot of the original scene as a still; it is not presented as a replacement animation.
